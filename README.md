Redesign af karriereplatformen KarriereVejviser.dk, udarbejdet som afsluttende eksamensprojekt på 4. semester Multimediedesign på KEA.

Projektet er lavet i samarbejde med Move On Career ApS, der står bag KarriereVejviser.dk og en række andre karriereportaler i Danmark.

## Sider:
- Forside (index.html): Hero med billede og CTA-knapper, stats-grid med platformens tre kernetilbud, "Hvad er KarriereVejviser"-sektion, "Din karriereprofil"-sektion og footer
- Om os (about.html): Hero med baggrundsbillede, introduktionstekst, video-sektion, "Viden og inspiration"-sektion og karrierenetværk-sektion

## Tech Stack
- HTML5
- CSS3
- Git/GitHub

## Sådan åbner du projektet
- Åbn projektmappen i Visual Studio Code og klik på "Go Live" nede i højre hjørne for at starte Live Server.
Sitet åbner på http://127.0.0.1:5500 (eller lignende).
